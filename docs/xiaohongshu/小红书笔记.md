## 正文

用 Kimi Code CLI 跑项目，有个很实际的问题：会话恢复太麻烦。

CLI 原生支持 `kimi -S <sessionId>` 恢复上次对话，但官方文档自己都写着「sessionId 没存的话没法恢复」。我日常三四个任务并行——一个爬虫、一个文档、一个数据处理——关机前得挨个复制 sessionId 存备忘录，漏一个就找不回来了。

所以写了个小工具，把这事自动化了。

**它做什么：**

扫描 `~/.kimi/sessions/` 下所有项目会话，一屏列出。每条会话显示项目目录、轮数、最后活跃时间。点「继续任务」直接拉起终端执行 `kimi -S`，回到上次的对话上下文接着干。

**几个实用的点：**

- 重命名会写回 kimi 自己的 state.json，不是工具私货，回 CLI 里名字也是对的
- 常用会话收藏置顶，开机点一下就行
- 界面支持中英切换，英文 README 也写好了，海外用户直接上手
- 做了双向交接：CLI 的会话能一键同步到 Kimi Work 桌面端继续；反过来桌面端的会话也能导出 markdown / JSON，或者直接生成一段紧凑交接文本（控制在 30KB 内），粘贴给 Claude、ChatGPT 或者别的 CLI 都能接上上下文
- 纯本地运行，零上传，零联网，所有数据不出本机

**技术栈没什么特别的：** Python 单文件后端 + 原生 HTML 前端，PyInstaller 打成单 exe。不搞 Electron，不装依赖，双击即用，放 U 盘里也能跑。同事机器上直接可用。

代码 MIT 开源，GitHub 搜 **kimi-session-manager**，Releases 里有现成的 exe。Windows 开箱即用，其他平台 clone 下来跑 Python 版。

有同样痛点的可以拿去用，有 bug 提 issue。
