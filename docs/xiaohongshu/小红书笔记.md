## 正文

姐妹们谁懂啊 😭 最近用 Kimi Code（终端版 AI 编程助手）干活，动不动就同时开 3、4 个会话，结果每次关电脑或者关掉终端，想接着上次聊的继续，都要去翻一堆看不懂的文件夹找什么 sessionId，真的崩溃……

一气之下我自己写了个小工具：**Kimi Code 会话管理器** 🛠️

✨ 它能干嘛：

📋 **所有会话一屏看全**
打开一个网页，电脑上所有 AI 会话按项目文件夹分好组，哪个会话最近在跑都标出来，再也不用一个一个试了

▶️ **一键回到对话**
点一下「继续会话」，自动帮你打开终端直接回到上次聊到一半的地方，和手敲命令效果一模一样，但不用记任何东西！

⭐ **重命名 + 收藏置顶**
可以给会话起中文名（会真正写进 kimi 的标题里），常用的点个小星星就置顶了

🔄 **跨 AI 交接**（我最爱的功能！）
在命令行里聊到一半的活，可以一键打包成「交接文档」，粘贴给桌面端 Kimi 或者其他 AI，它能完整看懂之前的上下文接着干，不用重新解释一遍 😭 反过来也支持！

💻 **怎么用（超简单）**
下载 exe → 双击 → 自动打开浏览器，完事！
不用装任何环境，电脑小白也能用 ✅

🔒 **隐私放心**
纯本地运行，只读你自己电脑上的会话记录，一个字节都不上传

工具已经开源放在 GitHub 了，链接在评论区 👇 用 Kimi Code 的宝子们快去试试！
